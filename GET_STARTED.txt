Welcome! This is your complete AI-powered Figma to Dashboard converter.

QUICK START (5 MINUTES):
------------------------

1. Install Python dependencies:
   > pip install -r requirements.txt

2. Setup API keys:
   > copy .env.example .env
   
   Then edit .env and add:
   - FIGMA_TOKEN (get from https://www.figma.com/settings)
   - OPENAI_API_KEY (get from https://platform.openai.com/api-keys)

3. Test your setup:
   > python test_setup.py

4. Run the application:
   > python app/main.py
   
   Or use the batch file:
   > run.bat

5. Open in browser:
   http://localhost:8000

TROUBLESHOOTING:
---------------

Problem: "FIGMA_TOKEN not configured"
Solution: Add your token to .env file

Problem: "OPENAI_API_KEY not configured"
Solution: Add your key to .env file

Problem: "No frames found"
Solution: Make sure your Figma file has Frames (press F in Figma)

Problem: Import errors
Solution: Run: pip install -r requirements.txt
